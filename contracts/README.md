**这个目录里的东西一旦冻结，谁都不许自己改。** 因为全项目的人都在依赖它。

## 改契约的流程（总纲 §3.3）

1. 冻结后的契约（`contracts/**`、`manifest.json`、数据字典）**不得擅自改**。
2. 需要改 → 写 `docs/rfc/RFC-<编号>-<标题>.md`，写清：**动机 / 影响面 / 迁移方案**。
3. 由主人（或云昔）批准后，**T03 统一改契约文件**，各模块再跟进。
4. **未批准前，允许"加字段"，禁止"删 / 改字段"。**

## 为什么这条规矩要写在墙上

因为这是单个系统里唯一会"一次改动打断所有人"的地方。
13 张卡并行推进时，契约是它们**唯一的共同坐标系**。
坐标系一歪，所有人的产出就都白做了。

> 发现契约有问题？**别自己改。** 去 `docs/issues/` 写一张卡，或者提 RFC。
