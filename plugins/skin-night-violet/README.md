# 夜紫皮肤（示例皮肤插件）

一个**只贡献皮肤、不提供任何窗口与接口**的插件。用来演示「皮肤是插件的一种能力」。

```
manifest.json   ← "skin": "skin.json" 这一行就是全部魔法
skin.json       ← alongsideSkin:1 格式，与用户自己导入的皮肤包完全同构
```

## 它做什么

装上前提：插件启用后，外观面板的「插件皮肤」分组里多出一份「夜紫」，
点「应用」才生效（不自动覆盖你的外观）。

停用插件 → 这份皮肤从分组里消失；如果正在用，自动回退默认。

## 怎么写自己的皮肤插件

1. 复制这个目录，改 `id` 与 `name`（`id` 必须与目录名一致，G 门禁会查）
2. 改 `skin.json` 里的令牌值 —— 格式见 `docs/示例/skins/README.md`
3. 跑 `python tools/gates/verify_plugin_skin.py`，绿了就算合格

`entry` 保持空串：皮肤插件不加载任何前端代码，**它只是数据**。
